# English Notebook

Тетрадь по английскому для занятий с ученицей: правила, упражнения с проверкой, словарь с картинками, аудирование и перевод.

Открыть: файл `index.html` (или ссылка GitHub Pages, если она включена в настройках репозитория).

Правки, которые делаются на странице, сохраняются в браузере того, кто их сделал.

Фотографии в словаре взяты с Wikimedia Commons и Openverse по свободным лицензиям. Авторы и лицензии указаны на странице под таблицей словаря.
